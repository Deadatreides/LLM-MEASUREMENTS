# agent_fork1_three_paths

Пятнадцатый пакет поверх ASSEMBLE-линии (но, как DELTA-0, не сам
ASSEMBLE). DELTA-0 нашла Δ=-0.500 на F2: LLM-исполнитель фильтровал
неточно (recall 0.82, precision 0.55), exact-set чекпойнт не прощал,
whole's мягкий ДА/НЕТ — прощал. FORK-1 разводит два раздельных вопроса
одним прогоном: **Path A** — была ли проблема в ИСПОЛНЕНИИ (те же атомы
на детерминированном коде вместо LLM)? **Path B** — было ли DELTA-0's
threshold-ДА/НЕТ необычно снисходительным (тот же LLM-исполнитель на
T_hard=EXTRACT-SUM, где финал — точное число, не порог)? **Path C** —
продуктовая спека из фактов A/B, без новых вызовов.

```
python scripts/verify_seams.py   # Path A self-test (40/40 vs delta0 golden) + T_hard fixtures
python scripts/run_all.py         # K1..K10 строго по порядку -> REPORT_FORK1.md
```

Итог — `reports/REPORT_FORK1.md`: **Path A**: `r_A=1.000` (детерминированные
атомы решают F2 идеально), `Δ_A=+0.475` — помечено `TOOL_PIPELINE`, не
победа роя. **Path B** (T_hard=EXTRACT-SUM, транзакции/JOIN-фильтр →
точная сумма): `r_m*_B=0.000` — **ни одна из 6 моделей ни разу** не
вывела точную сумму целиком (forensically подтверждено: ~35% просто
перечисляют слагаемые, ~65% выводят одно число, но неверное — маленькие
модели не считают точно). `r_∪_B_LLM=0.025` (тот же FILTER-провал, что
в DELTA-0, 39/40 обрывов), `r_∪_B_DET=1.000` (детерминированный tool-
потолок). `Δ_B_LLM=0.025` (не дотягивает до порога 0.05 — LLM-рой не
"имеет смысла" по формуле §6 PROTOCOL.md), `Δ_B_DET=1.000`. Корзина —
**`FORK_TOOL_ONLY`**: инструменты (детерминированный код) решают и F2, и
T_hard практически идеально; ни LLM-декомпозиция, ни LLM-целиком не
справляются с точным финалом на этих 1-2B моделях. Next: продукт = whole
+ det tools; LLM-рой на 1-2B не приоритет.

Два инфраструктурных бага найдены и исправлены ПОСЛЕ первого (упавшего)
прогона — тот же класс, что уже дважды встречался в DELTA-0 (см. память
проекта): значение, возвращённое для step_log, спутано с сохранённым в
`state`, и отсутствие persist полного raw-текста live-ответов. Оба
исправлены, полный прогон повторён — результат побитово идентичен
первому, падение было чисто инфраструктурным.
