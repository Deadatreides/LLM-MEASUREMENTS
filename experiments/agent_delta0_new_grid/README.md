# agent_delta0_new_grid

Четырнадцатый пакет поверх ASSEMBLE-линии, но НЕ ASSEMBLE — первый
полностью независимый полигон (0 Evolution/HGT/mutate/Pareto/stall/block
registry/ASSEMBLE-генотипов, 0 чтения `arch2/`/`experiment14/`). Отвечает
на вопрос, оставленный LIFE-9 открытым: LIFE-9 нашла на СТАРОМ полигоне
(HETEROSTEP), что недекомпозированный whole-task запрос бьёт весь
степ-декомпозированный аппарат проекта — а декомпозиция, изобретённая
маленьким planner'ом, проигрывает ещё сильнее. Было неясно: декомпозиция
как таковая бесполезна, или дело в конкретном плохом planner'е? DELTA-0
убирает planner'а (золотой, не LLM-изобретённый план) на НОВОМ, другом
T (transactions/JOIN-фильтр, не HETEROSTEP), измеряет: даёт ли
оракул-маршрутизированная цепочка атомов (`r_∪_lower`) зазор над лучшей
одиночной моделью (`r_m*`)?

Пакет процедурно строгий: `CHECKLIST.md` создан дословно из задания,
`run_all.py` идёт C1→C13 без остановки к заказчику, отмечает `[x]` и
пишет `metrics/step_log.jsonl` после КАЖДОГО шага.

```
python scripts/verify_seams.py   # C4: 5 фикстур generator/oracles, CPU-only
python scripts/run_all.py         # C1..C13 строго по порядку -> REPORT_DELTA0.md
```

Итог — `reports/REPORT_DELTA0.md`: `r_m*=0.525` (`qwen3-1.7b-q4_0-unsloth`,
whole-task, ДА/НЕТ-only). `r_∪_lower=0.025` (золотой план, тот же executor,
честная цепочка FILTER→AGGREGATE→DERIVE, обрыв без golden-подстановки) —
**39/40 обрывов на FILTER**. `Δ = -0.500` → корзина **`DELTA_NONPOS`**
(механически, порог не двигался). Forensic (не меняет корзину, раскрыт
рядом): executor не угадывает случайно (0/40 совсем мимо), но точность
JOIN-фильтрации (precision 0.545, recall 0.819) недостаточна для
СТРОГОГО совпадения множеств, которое FILTER-чекпойнт требует — тот же
самый неточный вызов, будучи частью мягкого whole-task ДА/НЕТ, часто всё
равно даёт верный ответ. Next: сменить T или атомы, не отбор/HGT.

Два инфраструктурных бага найдены и исправлены ПОСЛЕ первого прогона
(не повлияли на итоговое число — раскрыты в BLOCKERS.md): собственная
проверка C13 была противоречива по построению и не ловилась главным
циклом; детальные raw-ответы цепочки атомов не сохранялись на диск —
C9 пересчитан адресно для деталей, результат воспроизвёлся побитово
идентично.

Изоляция: пишет только в `agent_delta0_new_grid/`. Читает только
`experiment11/configs/model_registry.py` (`load_model`/`generate`, по
прямому пути файла — коллизия sys.path с `arch2/`, дважды найденная в
LIFE-8/LIFE-9, здесь исключена с самого начала). `arch2/`,
`experiment14/`, `agent_life*/`, `agent_a5*/` не читались.
