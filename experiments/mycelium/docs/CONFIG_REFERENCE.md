## models.yaml

Формат каждой модели:

```yaml
- id: groq_llama33_70b          # Уникальный ID в системе
  provider: groq                  # Провайдер (groq/deepseek/openrouter/...)
  endpoint: "https://api.groq.com/openai/v1"  # OpenAI-совместимый URL
  model_name: "llama-3.3-70b-versatile"       # Имя модели в API
  family: llama                   # Семейство (llama/qwen/gemma/...)
  cost_per_1k: 0.0                # Стоимость за 1K токенов (0 = бесплатно)
  max_rpm: 30                     # Rate limit в requests per minute
  ctx: 8192                       # Максимальный контекст (токены)
  roles: [G, C, S]                # Роли: G=Generator, C=Critic, S=Synthesizer
  mu: 0.5                         # Начальное μ (Thompson)
  sigma: 0.5                      # Начальное σ (Thompson)
```

### Добавление новой модели

1. Открыть `config/models.yaml`
2. Добавить новый элемент в список `models:`
3. Убедиться что провайдер есть в `PROVIDER_KEYS` в `orchestrator.py`
4. Добавить API-ключ в `.env` если новый провайдер

### Отключение модели

Добавить `disabled: true` или удалить из списка:
```yaml
- id: google_gemini25_flash
  # ... параметры ...
  sigma: 0.65   # высокое σ → почти никогда не выбирается
```

Или просто снизить mu и повысить sigma — система сама перестанет её использовать.
