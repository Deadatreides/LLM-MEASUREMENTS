## A. КРИТИЧЕСКОЕ: параметр порядка η не реализует критерий эмерджентности

**Матописание §16:** `J_total↑ ⇒ η↑` — это заявлено главным критерием.

**Python** (`telemetry.py:251`) реализует это буквально:

```python
a = eta_a * (2.0 * j_total - 1.0) + chi_gain * chi     # eta_a=1.0, chi_gain=0.08
```

Управляющий параметр `a` определяется **в первую очередь негэнтропией** (`2·J_total − 1`),
а `χ` входит малой поправкой с коэффициентом 0.08.

**Мой код** (`myc-thermo.cpp`):

```cpp
const float a = myc_clamp(th.chi - chi_c, -1.0f, 1.0f);   // chi_c = 0
```

`a` определяется **исключительно χ**, а `J_total` не участвует вообще.

**Следствие:** мой η реагирует на дисбаланс Пригожина, но не на негэнтропию. Критерий
§16 не реализован. Это не приближение — это другая динамика.

Сопутствующие расхождения в том же месте:

| Параметр | Python | Мой код |
|---|---|---|
| `tau_eta` | 6.0 | 8.0 |
| `eta_init` | **0.35** | 0.0 + костыль-затравка |
| `dt` | 1.0 (явный) | отсутствует |

Мой «seed so the pitchfork can leave η = 0» — костыль под проблему, которой в вашем
дизайне нет: у вас η инициализируется в 0.35, то есть сразу внутри полосы `0 < η < 1`
из §16.

чем у вас.

## C. КРИТИЧЕСКОЕ: J_kv считается по другой формуле

**Python:**
```python
j_kv = clip(0.65*(1 - kv_miss) + 0.35*(1 - kv_occupancy), 0, 1)
```
Два члена: промахи **и** заполненность.

**Мой код:**
```cpp
th.j_kv = myc_clamp(org.runtime.kv.hit_rate, 0.f, 1.f);
```
Только hit_rate. Заполненность не учитывается.

Также `j_spec`: у вас при `drafted == 0` возвращается **0.5** (нейтраль), у меня —
затухающая EMA, которая уползает к нулю, когда спекуляция не работает. Это разные
семантики «нет данных».

## D. УНАСЛЕДОВАННАЯ ОШИБКА: знак V(R) противоречит и матописанию, и Python

**Матописание §4:** `V(R) = αB + βQ + γM + δE − ρJ_total`, `V > V_crit → emergency`.
Высокое V = плохо.

**Python** (`telemetry.py:415`, `epochs.py:146`) — обе реализации согласны:
```python
V = 0.35*pressure + 0.25*stall + 0.20*migration + 0.20*thrashing - rho*negentropy   # rho=0.18
```
Высокое V = плохо. ✓

**Исходный guardian substrate** (сохранён мной без изменений):
```cpp
if (v_lyapunov > 0.f && v_lyapunov < v_lyapunov_min)  →  VETO_QUALITY_DROP
```
**Низкое V = плохо. Инвертировано** относительно вашей же математики и вашего же Python.

**Мой epoch-код:**
```cpp
critical = v_lyapunov > v_lyapunov_min && veto != NONE      // высокое V = плохо ✓
```

Итог: **в коде сейчас живут обе конвенции одновременно**, на одном и том же поле и с
одним и тем же порогом. Я пометил это как открытый вопрос ещё в
`MYCELIUM-TARGET-ARCHITECTURE.md` §Part 4, не получил решения — и затем добавил вторую
конвенцию рядом, вместо того чтобы остановиться. Это моя ошибка процесса.

Теперь свидетельство однозначно: **guardian неправ**, потому что матописание и Python
согласны между собой.

Веса V(R) у меня тоже не ваши:

| Член | Python | Мой код |
|---|---|---|
| pressure | 0.35 | 0.30 |
| stall | 0.25 | 0.20 (отображён на `collapse_rate`) |
| migration | 0.20 | 0.20 ✓ |
| thrashing | 0.20 | 0.10 (отображён на `C_hilbert`) |
| ρ (негэнтропия) | 0.18 | **0.40** |

ρ завышен более чем вдвое.

## F. ОТСУТСТВУЕТ: σ̂ (sigma_hat) — главная валюта решений

собственный `sigma_proxy = 0.45·h_attn + 0.35·curvature + 0.20·drift` (в гвардиане),
который **не совпадает** ни с чем в вашем Python.

## G. Окно спекуляции: другая логика гейта

**Python** (`telemetry.py`):
```python
if sigma_hat >= max_sigma_hat: return 0, True
if behavioral_drift > 0.55 or j_delta < -0.08 or curvature > 0.95: return 0, True
stability = clip(0.55*j_total + 0.30*max(j_delta,0) + 0.15*(1-sigma_hat), 0, 1)
window = round(stability * max_window)
```

Ключевое: гейт по **`j_delta < −0.08`** — то есть по *падению* негэнтропии, ровно как
требует §12 («если J_total↓ … k_draft↓»). И окно — непрерывная функция стабильности.

**Мой код** (`myc-spec.cpp`): гейты по `force_off`, `EMERGENCY`, `h_attn`, `σ_proxy`,
`v_lyapunov`; затем `k/2` при `acceptance < 0.5`. **`J_total` и `j_delta` не
используются вообще.** Требование §12 не реализовано; `j_delta` в C++ вообще не
вычисляется.
